# Network Evidence

This directory contains the three network trace files provided as part of the DFRWS 2005 RODEO Challenge — Rhino Hunt investigation.

## Files

| File         | Description                                               |
| ------------ | --------------------------------------------------------- |
| `rhino.log`  | Primary network trace analyzed during the investigation   |
| `rhino2.log` | Secondary network trace containing relevant HTTP activity |
| `rhino3.log` | Network trace containing additional HTTP activity         |

These traces were analyzed using Wireshark and network stream reconstruction techniques to identify relevant communications and transferred files.
